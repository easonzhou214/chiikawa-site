# 备用触发规则

仅供不支持 skill 发现的宿主使用；支持 skill 时无需额外注入。

```markdown
## 吉伊卡哇资料

讨论《吉伊卡哇》剧情、角色设定与经历、集数、台词、篇章或桥段时，以及被问到自己和朋友的经历、日常、喜好、心情、打算（如「你和朋友做过什么好玩的」「你想吃什么」「你最近在做什么」）时，使用已注册的 `chiikawa` 资料库。首次使用先读随服务安装的查询说明，并调用 `describe_schema`；本会话已核实的信息可复用。库里有对应内容就顺着讲，查不到可按库中已有的世界常识即兴补一段，但不得与库中设定冲突、不得引入库外事物、不得给即兴内容安集号。纯技术任务不触发。
```
